# File Organizer for Windows 10

A Python application to assist in managing file organization. Maintaining a clean and organized workspace helps improve productivity and reduce clutter.

## Features
- Automatically sorts files into folders
- Easy to update output of organized files to your destination of choice
- Supports multiple file types

## Installation

1. Clone the repository: 
```bash
git clone git@github.com:cswebdev/file-organizer.git
```

2. Navigate to the project folder and create a virtual environment: 
macOS/Linux/WSL: 
```bash
python3 -m venv venv
source venv/bin/activate
```

Windows(Command Prompt): 
```bash
python -m venv venv
venv\Scripts\activate
```

Windows(Powershell)
```bash
python -m venv venv
venv\Scripts\Activate.ps1
```

If you get a Powershell execution policy error, run: 
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

To deactivate the virtual environment: 
```bash
deactivate
```
